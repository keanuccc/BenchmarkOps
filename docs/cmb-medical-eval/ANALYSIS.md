# CMB 中文医疗问答评测结果分析（关闭 V4 思考模式版）

## 结论

本次使用公开 **CMB 中文医疗基准**（Apache-2.0），按 `exam_type -> exam_class`
分层采样：

- 单项选择题：280 道
- 多项选择题：169 道

通过七牛云 AI 网关评测两个真实模型：

| 数据集 | 模型 | 准确率 | 正确/总题数 | 错误题数 | 平均延迟 | 总 token |
|--------|------|-------:|-----------:|---------:|---------:|---------:|
| 单选题 | DeepSeek V4 Flash | 86.79% | 243 / 280 | 37 | 2,360.8 ms | 51,191 |
| 单选题 | DeepSeek V3 | 90.36% | 253 / 280 | 27 | 1,998.9 ms | 29,600 |
| 多选题 | DeepSeek V4 Flash | 69.23% | 117 / 169 | 52 | 3,262.1 ms | 43,166 |
| 多选题 | DeepSeek V3 | 57.99% | 98 / 169 | 71 | 2,346.2 ms | 19,733 |

所有实验均完成全部样本，0 个 provider 错误、0 个 metric 错误。

## 本轮关键改动

上一轮 V4 被 `reasoning_content` 污染，导致大量“空答案”或“推理中间文本”被判 0。
本轮针对 V4 做了：

```python
params = {
    "max_tokens": 1024,
    "extra": {"enable_thinking": False},
}
```

同时在 Qiniu provider 中，当 `enable_thinking=false` 时，不再把
`reasoning_content` 回退成最终答案，只认 `content`。

## 统计显著性

### 单选题

- 配对样本：280
- V4 对、V3 错：8
- V4 错、V3 对：18
- **McNemar p 值 = 0.0755**

单选题上 V3 略高，但 p > 0.05，尚未达到严格显著。

Wilson 95% 置信区间：

- V4：82.32% ~ 90.26%
- V3：86.33% ~ 93.29%

### 多选题

- 配对样本：169
- V4 对、V3 错：24
- V4 错、V3 对：5
- **McNemar p 值 = 0.00055**

多选题上 V4 显著优于 V3，差距明显。

## 核心发现

1. **关掉 V4 思考模式后，结果明显正常多了**：V4 不再被推理链截断污染。
2. **单选题上两者接近**：V3 略高，但差异不显著。
3. **多选题上 V4 显著更强**：V4 69.23% vs V3 57.99%，p < 0.001。
4. **V3 延迟和 token 仍然更省**：适合成本敏感场景。

所以不能简单说 V4“全面碾压 V3”，但至少本轮显示：

- 单选：两者基本同一水平
- 多选：V4 明显更强

## 为什么 V4 没有“远远强于 V3”

需要提醒的是，这里对比的是：

- `deepseek/deepseek-v4-flash`（Flash 轻量版）
- `deepseek-v3`（V3 标准版）

Flash 版本本身更偏快速/低资源，不一定代表完整版 V4。若换成
`deepseek/deepseek-v4-pro` 或非 Flash 版，结论可能不同。

## 优化建议

1. **多选题优先 V4**：V4 显著更强。
2. **单选题可以按成本选型**：V3 略高但不显著，且更快更省 token。
3. **若想验证“V4 完整版是否远强于 V3”**，应把 V4 Pro 加入评测，而不是只测 Flash。
4. **保留 reasoning 模型专用配置**：`enable_thinking=false` + 只取 `content`，避免再次污染。
