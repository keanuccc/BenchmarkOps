## 执行摘要

- 本评估比较了 **GPT-4o mini (OpenRouter)**、**Doubao Seed 2.0 Pro (Qiniu)** 与 **DeepSeek V3 (Qiniu)** 三个模型在两个数据集上的表现：**THUCNews 新闻分类**（120 条样本）和 **ceval-qa 问答**（61 条样本）。
- 在准确率方面，**Doubao Seed 2.0 Pro** 在两个数据集上均取得最高分：THUCNews 为 **93.33%**，ceval-qa 为 **91.80%**。**DeepSeek V3** 在 THUCNews 上为 **84.17%**（与 GPT-4o mini 持平），在 ceval-qa 上为 **70.49%**，显著优于 GPT-4o mini 的 **55.74%**。
- 在延迟方面，**DeepSeek V3** 平均延迟最低（约 1.2 秒/请求），**Doubao Seed 2.0 Pro** 延迟最高（ceval-qa 上平均达 12.56 秒/请求）。
- 在成本方面，仅 **GPT-4o mini** 有实际计费数据；THUCNews 实验总成本 14.65 美元，ceval-qa 实验总成本 1.18 美元。Doubao 与 DeepSeek 成本记录为 0。
- 所有实验覆盖率均为 100%，系统级失败率（provider 错误、指标错误）为 0%，但存在部分模型输出为空或分类错误的情况。

## 失败分析

- 所有实验的 `failure_rate` 均为 0%，`provider_errors` 和 `metric_errors` 均为 0，系统级运行未出现中断。但各实验的 `failures` 列表记录了评分不匹配的样本（即模型输出与标准答案不一致），以下分析基于这些样本。

- **THUCNews 新闻分类错误模式**：
  - 类别混淆常见于「时政 → 财经」、「房产 → 财经 / 时政」、「时尚 → 娱乐」。
  - 例如，row_idx 1（时政新闻）被 GPT-4o mini 和 Doubao 均误判为「财经」；row_idx 11（时尚内容）被 GPT-4o mini 和 DeepSeek 均误判为「娱乐」。
  - 存在**空输出**现象：GPT-4o mini 有 3 次（row_idx 24、32、33），Doubao 有 1 次（row_idx 1），模型未返回任何分类标签，导致得分为 0。DeepSeek 在该任务无空输出。

- **ceval-qa 问答错误模式**：
  - 错误集中在**计算机网络**（如 TCP 确认号计算、交换技术判断）和**语言学**（构词法、音素区别）等专业知识点。
  - row_idx 9（TCP 确认号）三个模型均未答对：GPT-4o mini 选 C，Doubao 输出为空，DeepSeek 选 D，而正确答案为 B。
  - 同样存在空输出：Doubao 在 row_idx 9 输出为空；GPT-4o mini 和 DeepSeek 未出现空输出。
  - 整体上，ceval-qa 的准确率普遍低于 THUCNews（除 Doubao 外），说明模型在专业领域推理上仍有明显短板。

- **空输出风险**：空输出集中在 Doubao 和 GPT-4o mini 上，可能是模型未遵守“仅输出答案”的指令，或生成了被解析器丢弃的额外内容。这是一个需要优先解决的质量问题。

## 建议

- **优先高准确率场景**：推荐使用 **Doubao Seed 2.0 Pro**，其在两个数据集上准确率均为最高。但需接受其高延迟（平均 5–12 秒），适合离线批量处理或异步任务。
- **平衡延迟与准确率**：**DeepSeek V3** 在 THUCNews 上达到与 GPT-4o mini 相同的准确率，且延迟最低；在 ceval-qa 上准确率显著高于 GPT-4o mini。若系统对响应时间有要求，DeepSeek V3 是更优选择。
- **谨慎使用 GPT-4o mini**：其在 ceval-qa 上准确率不足 60%，且 THUCNews 实验产生了相对较高的成本。仅在需要其特定生态或接口能力时考虑使用。
- **修复空输出问题**：在提示词中明确要求“必须返回一个分类标签”，并在后处理中增加空值兜底逻辑（如重试一次或返回默认类别）。同时建议对输出格式进行结构化约束（如 JSON）。
- **针对混淆类别优化**：对「时政 vs 财经」「房产 vs 财经」「时尚 vs 娱乐」等高频混淆对，可增加 few-shot 示例或收集更多该类别数据做针对性微调。

## 下一步行动

1. **扩大评估样本量**：当前每个数据集仅 120/61 条，统计波动较大。建议扩展至 500+ 条以获取更可靠的准确率估计和置信区间。
2. **补全成本数据**：为 Doubao 和 DeepSeek 接入实际计费或估算成本，完成三方总拥有成本（TCO）对比。
3. **构建混淆矩阵**：基于全量输出统计各类别间的误判分布，定位系统性偏置，并据此调整类别定义或提示词。
4. **多版本 Prompt 实验**：当前所有实验 `prompt_version=1`，可设计 v2（增加格式约束、示例、推理步骤）对比对准确率和空输出率的影响。
5. **延迟优化**：对 Doubao 尝试批处理、流式输出或降低最大 Token 数来压缩响应时间；对 DeepSeek 可进一步压测高并发场景下的稳定性。
6. **专业领域专项评估**：针对 ceval-qa 中的计算机网络、语言学等薄弱科目，引入领域知识库或 RAG 增强，并重新评测。
